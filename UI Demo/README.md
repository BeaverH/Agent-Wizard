# Agent Wizard UI Demo v0.4

基于 [PRD v0.4](../agent-wizard-prd-v0.4.docx) 及后续协作方案迭代，包含任务共享上下文、子任务成果接力、Guardrail 治理和 Skill 共享能力。独立 React + TypeScript + Vite 纯前端演示，Builder、User Portal、Manager 共享浏览器内的 Agent、版本、审批、执行、反馈和审计记录。

## 启动

```powershell
cd '.\UI Demo' # 从仓库根目录执行
npm ci
npm run dev
```

访问 <http://127.0.0.1:18123/#portal/tasks>。已安装依赖后只需运行 `npm run dev`。应用使用 hash 路由，无需后端路由重写；请通过 HTTP 服务访问。

```powershell
npm run test:work
npm run test:governance
npm run test:skills
npm run build
npm run preview
```

状态测试需要支持 TypeScript 类型擦除的 Node 22.6+；当前使用 Node 24。生产构建位于 `dist/`，预览地址为 <http://127.0.0.1:18124/>。

## 协作模型

- 一个协作任务（Work）是一次交付的协作空间，包含总协作与按需创建的专题会话，共用一个当前目标和一个主交付物。单 Agent、单人多 Agent、多人多 Agent 使用同一容器。
- 新任务默认只有总协作。负责人和协作者可新建专题，并从任务已批准的 Agent 中选择参与者；所有真人成员的角色和历史范围继承任务。会话不单独配置私密权限。
- 各会话共用任务级上下文：目标、共享资料、已批准决策和带版本的子任务成果。聊天保留讨论过程；已移除消息发布和转发入口，历史来源仍可回看。
- “共享上下文”展示现有工作记录，不额外维护一份摘要。通过子任务提交或修订成果，自动进入共同工作依据，保留作者、来源、目标修订及版本；已提交成果仍应按业务要求核验。
- 子任务通过“设置依赖”选择所需的上游成果。上游未就绪时禁止启动；启动时冻结本次采用的版本和完整输入。其他会话的完整聊天不自动加入执行输入。
- 上游成果修订后，受影响的下游显示“输入已更新”，需按依赖顺序更新执行或重新提交成果。旧版本与旧 Run 保留，过时成果不能汇总或验收。
- 先新建任务，再选择专用 Agent 或专家团队；「Agent 与团队」提供预选执行者的辅助入口。
- 负责人确认目标与范围变更、业务动作请求、成员与历史范围，并验收最新交付物。协作者可讨论、派发子任务和提交成果；观察者只读。
- 普通消息与 @ 提问不会自动执行任务。派发子任务、批准目标变更和批准业务执行是独立动作。
- 子任务属于任务分工，并关联来源会话、目标修订与独立 Run；Run 成功后仍需汇总、提交和负责人验收。变更目标使旧成果失效，新增依据需要重新提交成果版本。
- 失败子任务可以重试，保留历次 Run；业务动作重试需要负责人再次明确确认。
- 加入时可选择全部历史或仅加入后内容。衍生消息、成果和执行详情保留来源范围校验。个人记忆与其他任务内容不自动共享。
- 团队和 Agent 版本固定为任务快照。需要更新执行者时，通过负责人批准的范围变更显式重新绑定版本。

## 演示路线

1. 在左下角身份菜单选择 **User Portal**，进入「任务 → Q4 经营汇报」。示例包含 3 人、3 个 Agent、4 个子任务和一个主交付物。
2. 在「协作」中新建“财务口径核对”等专题会话，选择参与 Agent，讨论或 @ 专家。普通消息不生成 Run，也不自动成为共享成果。
3. 处理「增加渠道对比章节」：驳回可继续当前目标；批准会产生新修订，旧成果需更新，并重新派发当前修订的子任务。
4. 最短验收路线：驳回示例变更 →「任务详情」→ 启动「撰写与整合报告」→ 完成后进入「交付物」→「汇总成果」→「验收交付物」。
5. 使用「当前参与者」切换负责人和协作者，检查决策、邀请和验收按钮。邀请周予安时可选择观察者以及「仅加入后」历史范围。
6. 「请求执行」提交受保护业务动作，由负责人单独确认后生成执行记录；与目标变更审批分开。
7. 「新建任务」分别选择单 Agent 和专家团队，按需邀请同事。目录中无访问授权的 Agent 需先申请。
8. **Builder → 我的 Agents**：创建和编辑 Agent、选择资源、Playground 验证、提交发布。**Manager**：审批、模拟部署、上架、访问授权、反馈处理和审计。

成果接力路线：创建“报告撰写专家”任务并邀请林知夏 → 派发“核对财务统计口径”给林知夏 → 报告子任务设置依赖为财务任务 → 财务提交成果 v1 → 报告运行前查看“本次执行依据” → 修订财务成果到 v2 → 报告显示“输入已更新” → 更新执行后采用 v2。可在“已提交 · vN”中切换历史成果并核对实际采用的版本。

左下角提供 **Builder / User Portal / Manager** 切换；菜单内「重置演示数据」可恢复初始示例，操作前保留后果确认。

## 数据与边界

- 无后端、真实模型调用、真实多人同步、SSO、服务端鉴权、业务系统写入或生产部署。
- `agent-wizard-demo-v1` 保存基础资产；`agent-wizard-collaboration-v2` 保存协作任务。均为当前浏览器的 `localStorage`。旧协作记录在读取时迁入总协作，保留任务 ID、成员、消息和成果；不会重置浏览器数据。未保存 Agent 编辑暂存 `sessionStorage`。
- 「当前参与者」是本地角色模拟器。历史可见性、资源范围、业务确认和成员权限用于评审产品规则，不能替代服务端授权和真实多用户验收。
- Agent、团队与经营数据均为演示样例。成果汇总为本地模板，不生成真实经营分析。文本附件只在当前浏览器读取。
- Team 使用内置版本样例；团队编辑与发布治理尚未实现。长期记忆、生产并发编辑、后台调度和企业身份集成仍待后续实现。
- Work / Run 分离；Manager 的「执行状态」统计 Run，任务是否完成取决于 Work 的主交付物验收。

## 验证

`npm run test:work` 的 185 项断言覆盖依赖交接、执行版本冻结、传递失效、循环依赖、读取范围、迁移、历史成果、验收及业务动作保护；`npm run build` 执行 TypeScript 检查和 Vite 生产构建。

本轮浏览器走查以成果接力路线为准，检查待依赖时禁执行、提交成果后可开始、Run 输入包含指定依赖成果版本、上游修订后下游失效、更新执行后采用新版本。

此前版本已验证目标决策到负责人验收、观察者历史范围及失败重试。当前 [PRD v0.4](../agent-wizard-prd-v0.4.docx) 共 22 页，包含 Skill 三入口、绑定与发布规则；本地渲染和校对产物不纳入版本管理。


## Guardrail 治理演示

- Builder：Agent 卡片的 Ready / Limited / Not Ready 可进入“防护与评估”。生产版本和草稿修订分别保留评估证据；发布前需要匹配当前修订的开发验证与 Guardrail 验证。
- Manager：[安全与策略](http://127.0.0.1:18123/#management/policies) 展示 Profile → Guardrail → Policy 绑定及整改待办。右上角“演示事件”可触发疑似误报、动作防护撤销、必需防护撤销、严重漏报和共享防护撤销。
- 整改：确认接手 → 替换防护 → 模拟复测 → 模拟签署并恢复。确认接手、关闭反馈、服务重新启用均不解除治理限制；共享事件按实际演示引用传播。
- Portal：只显示可用、仅支持查询或暂不可用，以及本人执行的简短原因和误报反馈。已存在的任务、聊天和成果保留；创建、排队、重试、业务动作和人工确认后继续执行均检查治理门禁。
- 初始示例：合同审阅助手的敏感动作防护已撤销，查询能力保留；其访问授权保持独立。旧版浏览器数据自动补充治理演示数据，不重置已有任务。

数据仍保存在当前浏览器。Guardrail Measure 链接仅打开现有 Guardrail Demo，没有跨系统事件订阅、真实扫描或签署接口，也不替代服务端授权与执行防护。演示恢复只更改本地状态。

`npm run test:governance` 检查策略撤销、能力限制、版本依赖、草稿隔离、共享影响及恢复条件；`npm run test:work` 继续检查既有协作流程。

## Skill 共享能力

Manager 的共享资源新增 Skill 类型、筛选、版本与输入输出详情，并分别展示当前配置引用和生产版本引用。Builder 的共享能力新增 Skill 页面，可浏览并绑定到 Agent 草稿；未保存编辑存在时须先保存，绑定后按原流程重新验证、批准和部署。

User Portal 的发现新增 Skill 页面，展示概要及已交付 Agent。任务通过已交付并具备相应 Skill 的 Agent 发起，不单独运行 Skill；权限、服务及治理条件仍分别检查。普通用户不展示内部技能指令。

旧浏览器数据自动补充示例 Skill，历史发布不会被追补绑定。新部署保留 Skill ID、版本和指令快照。示例均为本地前端数据，无外部技能安装或真实模型执行。`npm run test:skills` 验证迁移、绑定资格、发布引用和快照边界。
